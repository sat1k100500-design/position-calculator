# Калькулятор позиции

Калькулятор позиции для USDT-M фьючерсов Binance: живая mark-цена, плечо, расчёт от маржи или от риска, ликвидация, комиссии, PnL на тейке и стопе.

Эффекты интерфейса — MIT-библиотеки с [libraries.dev](https://libraries.dev): distortion-waves, border-beam, thinking-orbs, liquid-gooey, metal-fx.

```
npm install
npm run dev
```
